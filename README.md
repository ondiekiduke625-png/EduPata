# EduPata Backend

Starter backend for EduPata. Designed for deployment as a Render Web Service.

Never commit Daraja Consumer Secret, M-Pesa Passkey, passwords, or OTPs to GitHub. Add secrets through Render Environment Variables.

Current endpoints:
- GET / 
- GET /health
- POST /api/register
- POST /api/payments/stkpush (placeholder until Daraja is configured)
